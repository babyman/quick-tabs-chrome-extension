To use Quick Switch mode:
• Press "Activate the extension" shortcut
• Hold Ctrl/Alt/Option/Command key for this delay
• Release the key to switch the tab
• Use Tab/Shift+Tab/Arrows to select a tab before releasing the key
• To cancel press Space/Left/Right/Delete/Backspace/Alt/Ctrl/Meta?
